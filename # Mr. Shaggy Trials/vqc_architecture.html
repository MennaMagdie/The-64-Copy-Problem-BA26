Why Shared Parameters?

The XXZ Hamiltonian has translation symmetry — every bond on the ring is identical. Our ansatz respects this: every IsingXX(θ₁) gate uses the same θ₁ regardless of which qubit pair it acts on. Same color = same trainable weight. This is weight tying, analogous to shared convolutional filters in CNNs.
📐

O(1) Parameter Count

Without sharing, a brickwall on N=16 qubits would need 2×16 + 16 + 2×16 = 80 parameters. With sharing: always 6. The count is constant regardless of system size. This prevents overfitting when training data is scarce and satisfies the competition's parameter efficiency requirement.
🔄

Zero-Shot Size Transfer

Because the 6 parameters don't depend on N, the same trained weights work on N=16, N=20, N=24, or any size. The brickwall simply tiles over more pairs. No retraining needed — the circuit generalizes to unseen system sizes out of the box.
⚡

Physics-Informed Gates

IsingXX probes transverse ⟨X·X⟩ correlations (dominant in XY phase). IsingZZ probes longitudinal ⟨Z·Z⟩ correlations (dominant in NEEL phase). RY and RZ mix and phase-shift — together they rotate the state into a measurement basis where phase differences are amplified.
